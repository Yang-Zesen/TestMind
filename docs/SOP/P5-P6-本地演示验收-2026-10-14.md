## P6 验收

- `scripts/demo_stack.ps1` 支持独立 demo/acceptance 配置与依赖启停；启动执行冻结依赖同步、迁移和模型指纹检查，`/ready?deep=true` 检查 API 与三个 Worker。
- 运维页显示 API/Worker 心跳和项目任务状态；队列按用户限额，瞬时失败有限重试。
- `uv run python scripts/measure_capacity.py --url http://127.0.0.1:26114`：256 请求，128 接受、128 因单用户队列上限拒绝；总耗时 26.437 秒，p50 20.320 秒、p95 25.750 秒、p99 26.156 秒。范围仅为一台本机的任务受理与 PostgreSQL，不含模型推理或多实例配额。
- `uv run python scripts/backup_demo.py backup --env-file deploy/acceptance.env --directory output/backups/p6-drill` 生成 PG 自包含 dump、原件归档及 manifest。
- `uv run python scripts/backup_demo.py verify-restore --env-file deploy/acceptance.env --directory output/backups/p6-drill`：还原耗时 3.359 秒；表计数、授权、版本和水位匹配，5 个原件恢复。隔离新 Milvus 集合重建 2 个有效文档/2 个 chunk，Neo4j 两个项目代际重建 14 个实体，投影校验通过。原卷未删除。
- `uv build --wheel` 成功，wheel 含 `testmind/demo/static/index.html` 和 `workflows.js`。Playwright 桌面和 390×844 移动视口验证无水平溢出；截图位于 `output/playwright/p6-desktop.png`、`output/playwright/p6-mobile.png`。
